# PWRG-Ichneumonidae

This repository contains a research report and supporting materials for a project in the ZHAW Research Group for Urban Ecology (PWRG).

## Project Description

The project aims to establish a knowledge baseline for Ichneumonidae (parasitic wasps) by synthesizing current literature, identifying key knowledge gaps, and mapping out researchers and institutions involved in the field — with a special focus on Switzerland.

This work will support future master's thesis planning and research initiatives in the domain of hymenopteran ecology and systematics.
